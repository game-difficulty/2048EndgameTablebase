## 压缩与 CDN

`backend/http_compression.py` 为主站/小游戏/人类站榜单、历史等展示 JSON 启用 gzip：至少 1000 B、级别 4。小回执不为压缩付出额外成本，已有 gzip 二进制回放不重复压缩。

Vite 在兼容 CSS 生成完成之后执行 `scripts/precompress.mjs`，为 HTML、JS、CSS、JSON、SVG、WASM 等产生更小的 `.gz` 旁文件；字体、图片已有压缩格式，不重复生成。源站按 `Accept-Encoding` 协商发送，支持 `gzip;q=0`、ETag/304、`Vary: Accept-Encoding`，Range 请求使用原文件。哈希资源保留一年 immutable 缓存头，入口使用重新验证策略。构建目录必须整体发布，不能漏掉 `.gz`。

本次构建生成 107 个预压缩文件：对应原文约 6.95 MB，gzip 约 3.38 MB。这是整站可预压缩文件汇总，不是人类站单次页面下载大小；旁文件也会增加约 3.38 MB 部署磁盘用量。

## 大回放准入与限流

人类站在读取上传请求体之前获取处理名额；超限返回 `429 + Retry-After`，不把大请求放入无界内存队列。请求体最多 1,000,000 B / 200,000 步，读取超时 20 秒。封局即使只补很短的尾部，也需要完整重演，因此始终计入大任务。

| 通道 | 单账号并发 | 源站总并发 | 单账号每自然分钟次数 |
| --- | ---: | ---: | ---: |
| >8 KiB 上传、无长度上传、所有封局验证 | 1 | 2 | 12 |
| ≤8 KiB 的非封局增量/重入等 | 4 | 16 | 120 |
| 已存回放下载 | 1 | 4 | 10 |

这些名额按账号计算，跨浏览器、跨变体共用。未登录的公开回放读取按 IP 限制。大上传、普通增量、下载分通道；大任务不会占用在线心跳通道。下载在读取 BLOB 前准入，分段返回，在响应完成/断连时释放名额。

默认值可用环境变量调整：`HUMAN_LARGE_PER_USER`、`HUMAN_LARGE_GLOBAL`、`HUMAN_LARGE_PER_MINUTE`；将 `LARGE` 替换为 `SMALL` 或 `DOWNLOAD` 可调整另外两组。全部为正整数，同一服务所有 worker 使用相同配置。

计数和处理名额放在相邻的 `*.traffic.sqlite3`，通过短事务跨进程一致，不是各 worker 各算一份。超过两分钟前的计数会回收，处理名额在正常结束时释放；进程崩溃遗留名额最迟 300 秒失效。该独立限流库使用 WAL/NORMAL，可在断电时丢失最近计数；它不保存反作弊证据。对局主库仍为 WAL/FULL，动作与防回档进度不会因此降低耐久性。

本地 Nginx 配置模板的 `/api/human/` 已加入 1 MiB 请求限制、20 秒请求体超时、关闭请求及响应代理缓冲。未来部署时应合并这些配置，防止应用准入前代理已完整缓存大上传。本轮未部署该模板，也未在生产执行 `nginx -t` 或 reload。

这些限制控制源站处理资源，不能替代公网带宽整形，不能保证下载期间恰好只占 0.5 Mbps。主站旧排位上传仍使用其原有队列、用户/IP 限额与后台验证；本轮的新回放通道限额应用于人类站。

## 验证与短期在线许可

正常提交先在只读事务中取得一致的对局/已留存分段快照，关闭事务后增量验证；封局还从种子独立完整重演、比对全部状态并压缩。读取大量小分段采用连续缓冲，不为每一步长期保留一个 Python 行对象。

完成计算后才 `BEGIN IMMEDIATE`，重新核对当前快照：序号与前缀（state）、writer、epoch、资格、状态、种子、阈值等。任一变化返回 `progress_changed`，旧验证结果不会落库，也不会用旧证据把新状态误判作弊。新动作、检查点、归档与状态变更原子提交，提交成功之后才 ACK；幂等重试与回档/前缀冲突审计继续生效。站长手工准入的完整验证和压缩也已移出写事务，落库前重新核对证据。

人类站心跳改为 12 秒 HMAC 签名许可，绑定账号、浏览器、对局、writer 和 epoch。服务端密钥在对局库 `human_keys` 初始化一次，多 worker 共享；不是进程重启时随意更换的内存秘钥。客户端携带许可续期/追加，许可过期仍必须重入校验；更换 epoch、失格、封局或账号会话撤销后不能凭旧许可继续追加。

每次在线检查仍从数据库读取当前身份、对局状态和资格，只是不再更新 `permit_until`。首次越线、动作追加、重入等真正状态变化仍耐久写入。状态接口只能返回既有期限，不会凭空延长在线许可。5 秒检查、12 秒许可、动作留档改为有新增动作时每 20 秒或累计 32 步上传（先到为准）；服务器不恢复或覆盖本地棋盘，也不负责逐步出数。

人类站与主站普通排位、小游戏排位接口使用新的精简身份鉴权，仍实时检查用户状态、会话过期和撤销，只查身份所需列，不读取余额、权益或完整个人资料。主站两套原有写入租约协议未在此轮改成签名协议；本轮替换的是人类站高频在线许可。

收到限流且现有在线许可仍有效时，客户端保留输入并遵守上传退避；真正失联、许可失效或作弊判定仍有相应限制。历史补传失败留在本地等待重试，不清除记录。
