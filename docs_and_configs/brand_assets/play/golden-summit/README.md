# Golden Summit brand concepts

These files preserve the selected visual direction for the play site. They are
design sources and are not loaded by the frontend.

- `golden-summit-key-art-a.png`: original Golden Summit key visual.
- `golden-summit-emblem-a1.png`: detailed illustrated emblem.
- `golden-summit-icon-a2-master.png`: selected official icon master.
- `golden-summit-sculpture-a3.png`: freestanding sculptural mark.
- `golden-summit-crest-a4.png`: decorative crest.

Runtime favicon and touch-icon derivatives are stored in
`frontend/public/human/brand/`. Generate smaller sizes from the A2 master; do
not repeatedly rescale an already reduced derivative.
