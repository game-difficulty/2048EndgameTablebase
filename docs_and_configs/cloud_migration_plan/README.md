# 2048 Endgame Tablebase 云化迁移计划

更新时间：2026-08-27

本目录记录 `C:/Apps/2048endgameTablebase/src - cloud` 副本的云化迁移设计、代码位置、风险判断、基础模块和下一步工作计划。后续开始实现前，优先阅读本目录，避免重复全量阅读代码。

## 当前结论

云化可行。现有项目已经是 Vue 3 前端 + FastAPI/WebSocket 后端的前后端分离形态，`pywebview` 主要承担桌面启动和文件对话框职责，不是核心业务运行条件。

云化时必须拆分三类状态和能力：

- 服务器定式表库：后端只读、白名单管理，真实路径不暴露给浏览器。
- 浏览器本地状态：用户 UI 设置、小游戏进度等改为 `localStorage`。
- 文件输入输出：本地文件路径改为浏览器上传，保存文件改为浏览器下载。

## v1 范围边界

v1 目标是把现有训练、测试、回放、分析、小游戏、设置和帮助中适合云服务的部分迁移出来，并移除不适合开放给用户的本地/重计算能力。

注册、登录、频率限制、积分和付费使用定式只做架构预留，不在 v1 实现。
