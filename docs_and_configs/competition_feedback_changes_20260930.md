# 赛事测试反馈：已明确需求实现（2026-09-30）

## 权限和人员管理

- 赛事管理员可管理所有比赛房间；房主可管理自己创建的房间。没有新增队长踢人权限。
- 所有阶段都提供人员管理入口。可移出席位人员，也可按用户 ID 移出其他人员；提供取消移出、允许重新进入操作。
- 落座／准备阶段移出选手时清空对应席位并撤销准备，回到落座阶段。
- BP／布阵阶段移出已落座选手时阻止手动、自动推进；赛事方需处理或关闭房间。不会静默替换已密封的安排。
- 赛中移出选手时保留其席位历史、对局与成绩，暂停对局和包干时钟。允许重新进入不等于恢复比赛，仍走现有恢复确认流程。
- 被移出者不能重新进入、提交指令或上传对局；已连接客户端收到通知后停止本地运行并断开连接。操作写入赛事事件。

## 阶段停留

| 环节 | 停留／推进条件 |
| --- | --- |
| 先后手抽签结果 | 10 秒 |
| 双方盲选候选公开 | 10 秒，暂不公布 C |
| C 抽签结果、三个项目展示 | 再停留 10 秒 |
| 每局开局检查 | 至少展示 10 秒，双方出战者和队长全部就绪后自动开始 |
| 单局结果和休整 | 至少 30 秒，双方队长均确认后自动继续 |

首局还保留抽签结束后至少 60 秒的下注窗口，以两个条件中更晚满足者为准。开局展示与休整不扣包干时间。队长可在休整中提前确认；后台定时任务在时间到达后推进，无须裁判操作。裁判强制跳过确认也不能跳过休整最低时长。

## 认输

- 只有本局仍在进行的出战选手可操作，不开放给队长代按或观众。
- 对手本局已完成且不是认输完成时才可认输。按键二次确认，无认输快捷键。
- 保留认输时盘面、成绩和用时；即使成绩更高仍判负。时间立即冻结，下一局仍可使用余下的队伍时间。
- 由服务端在同一事务中检查条件、记录结果，保证一局最多一方认输；重复上传不重复结算。

## 界面和交互

- BP 和盲选项目卡保留项目 A、项目 B、黄方 BAN、白方 BAN 标记。
- 双方全部提交布阵后，三场完整对阵向双方、赛事方和直播观众公开；提交完成前仍保密。
- 选手页、直播结果页保留双方终局棋盘，展示休整与确认进度。直播结果区支持滚动，避免固定行高造成重叠。
- 支持重开的项目增加 R 快捷键，撤销继续使用 Z；适用于比赛页和练习页，不能绕过项目限制。
- 问题上报增加明确关闭按钮，说明上报不自动暂停以及无人值守时需另行联系赛事方。
- 使用“黄方队长／白方队长”文案。单局计时保留百分秒展示与本地插值，终局冻结精确用时。
- 布阵拖动排序属于此前可选设计，本次未改动现有选择控件。
